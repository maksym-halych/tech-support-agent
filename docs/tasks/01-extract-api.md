# Task 1 — Extract the API into `api/`

## Goal

Move the booking API out of the agent package into its own uv project at the repository root, next to `agent/` and `frontend/`. Behaviour stays the same in this task; the domain changes in task 2.

## Current state

- The service lives in `agent/src/tech_support_agent/demo/api.py` and is started with `support-demo-api`.
- `fastapi` and `uvicorn` are only dev dependencies of the agent, although the demo is a runnable script.
- `agent/examples/lessons.openapi.json` is exported from it by `support-export-openapi`.
- Agent tests build the demo app in-process: `tests/conftest.py`, `tests/test_api.py`, `tests/test_graph.py`, `tests/test_tools.py`, `tests/smoke_demo.py`.

## Changes

1. Create `api/` as a uv project (`uv init --package`), Python 3.14, package `lessons_api`, build backend `uv_build`, matching the agent's ruff and pytest configuration.
2. Move the service:
   - `agent/src/tech_support_agent/demo/api.py` → `api/src/lessons_api/` split into `app.py` (FastAPI factory `create_app`), `models.py` (Pydantic schemas), `auth.py` (current demo token check), `storage.py` (SQLite) and `main.py` (CLI entry point).
   - Runtime dependencies: `fastapi`, `uvicorn`, `pydantic`, `pydantic-settings`. Dev: `pytest`, `httpx`, `ruff`.
   - Settings via `pydantic-settings` with the `LESSONS_API_` prefix: host, port, database path (`data/lessons.sqlite`).
   - Scripts: `lessons-api` (serve) and `lessons-api-export-openapi`.
3. Move the API's own tests (endpoint behaviour currently covered from the agent side) into `api/tests/` and use FastAPI's `TestClient`.
4. Agent side:
   - Delete `agent/src/tech_support_agent/demo/` and its scripts from `agent/pyproject.toml`.
   - Keep the agent tests working until task 3 removes the generic stack: add the API as an editable dev dependency (`uv add --dev --editable ../api`) and import `lessons_api.app.create_app` instead of the demo.
   - `agent/examples/lessons.openapi.json` is regenerated by the API's export script.
5. Tooling:
   - Makefile: `api` target (`uv run --directory api lessons-api`), `install`, `test` and `lint` cover both Python projects.
   - `.claude/launch.json`: rename `demo-api` to `api`, pointing at the new command.
   - `.gitignore`: `api/data/`.
   - `.pre-commit-config.yaml`: make sure ruff runs over `api/` too.
6. Docs: README and CLAUDE.md layout sections list `api/`.

## Acceptance criteria

- `make api` serves the same endpoints as before on port 8001, with Swagger at `/docs`.
- `uv run --directory api pytest` and `uv run --directory agent pytest` pass.
- `ruff check` and `ruff format --check` pass in both projects.
- Nothing under `agent/src` imports FastAPI.

## Out of scope

Roles, Clerk, new lesson endpoints (task 2).
